## 認証アプリの記録の範囲

- アプリの準備・選択だけでは対象AccountのMFAを完了しません。スキャンと、同じ登録操作に対するサービス側の確認を対応付けます。別Account・別アプリや、過去の登録の確認を流用しません。
- 値を持たないコード・端末上のアプリ・対象Account・実際の同期先を区別します。登録時の受け付けは `enrollment` とし、通常／新端末ログインや復元試験へ変換しません。
- 後日の有効状態確認だけでは登録観測の日時を更新しません。再登録は別の値を持たないコードとして扱い、古いコピーの利用観測を未確認に戻します。履歴・バックアップ・未知項目を保持します。
- スキャン・サービス側確認の取り消しは派生する関係・観測も訂正します。外部サービスの認証を無効化したとは表示しません。他の記録に参照される経路を残します。
- Googleの同期先は本人が実際に確認した段階で不足する保護へ接続します。主メールを変更せず、同じAccountのMFA・復旧を再利用します。
- Microsoft・Bitwardenの今回のコードをローカルに保存する選択から、アプリ全体の同期・バックアップなしとは推測しません。今回の機種変更では、アプリ全体の実際の保存方式を別に質問し、確認した範囲の移行・実利用へ案内します。
